# Unit teaching loops

Put short, anonymised MP4 clips (H.264, a few seconds, < 5 MB each) in this folder, then list them in `../loops.json`, e.g.

```json
"plax": [ { "src": "atlas/loops/plax_normal_28wk.mp4", "cap": "Normal PLAX, 28 weeks, DOL 3" } ],
"ductal": [ { "src": "atlas/loops/pda_large_LtoR.mp4", "cap": "Large PDA, left-to-right flow" } ]
```

View keys: plax, psax_av, psax_pm, a4c, a5c, sub, ductal, arch, highps.
The clips appear under a 🎞 Loops tab in that Atlas view. Remove all patient identifiers (name, IC, MRN, dates of birth) before committing — the repository and site are public.
